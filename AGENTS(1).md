# LABAYKANUSUK — RÈGLE ÉDITORIALE OBLIGATOIRE

## INTERDICTION ABSOLUE DES GROS TIRETS

Dans tous les contenus LABAYKANUSUK, il est strictement interdit d’utiliser les caractères suivants :

- tiret cadratin : —
- tiret demi-cadratin : –

Cette règle s’applique partout :
- titres
- hooks
- légendes Instagram
- stories
- reels
- quiz
- textes de feed
- descriptions
- CTA
- fichiers JSON
- fichiers Markdown
- contenus Shopify
- textes générés ou réécrits

### Remplacement obligatoire

À la place, utiliser selon le contexte :
- une virgule
- un point
- deux-points
- des parenthèses
- une nouvelle phrase

Le tiret court `-` reste autorisé uniquement lorsqu’il est réellement nécessaire, par exemple dans un mot composé, un nom technique, une URL ou une structure de code.

## CONTRÔLE AVANT ENREGISTREMENT

Avant tout commit, toute génération de contenu ou toute livraison de fichier, vérifier qu’aucun caractère `—` ou `–` n’est présent dans les textes destinés au public.

Si l’un de ces caractères est trouvé, il doit être remplacé avant validation.

Cette règle est permanente et prioritaire pour tous les futurs contenus LABAYKANUSUK.
